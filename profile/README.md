# Incline

Tools and guides for working with AI coding agents.

| Project | What it helps with |
| --- | --- |
| [Coding Agent Guidelines](https://github.com/incline-ltd/coding-agent-guidelines) | Give coding agents clear rules for focused, verified changes. |
| [Awesome Agent Instructions](https://github.com/incline-ltd/awesome-agent-instructions) | Review and simplify coding-agent instructions while preserving project constraints. |
| [Awesome Agentic Engineering](https://github.com/incline-ltd/awesome-agentic-engineering) | Find useful tools and workflows for AI-assisted development. |
| [Agent Policy Map](https://github.com/incline-ltd/agent-policy-map) | Compare which instructions four coding agents can see for the same file. |
| [Agent Cost Guard](https://github.com/incline-ltd/agent-cost-guard) | Check proposed commands for supported cloud-cost rules before they run. |
| [Production Launch Prompts](https://github.com/incline-ltd/production-launch-prompts) | Review an app before launch with practical audit prompts and checklists. |

Agent Policy Map and Agent Cost Guard are source previews. Their READMEs explain setup,
coverage and current limits.

Found a bug or a useful resource? Open an issue in the relevant repository.
